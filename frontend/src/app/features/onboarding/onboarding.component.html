El concepto de acumulador

Un acumulador es una variable numérica que conserva el resultado intermedio de operaciones secuenciales dentro de un bucle.

Objetivo del reto: Escribe una función que sume solo los números pares de la lista.
solution.py Python 3.12
1 def sumar_pares(numeros):
2     total = 0
3     for n in numeros:
4         if n % 2 == 0:
5             total += n
6     return total
